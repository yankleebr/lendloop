# Start Action

1. Read current-feature.md - verify Goals are populated
2. If empty, error: "Run /feature load first"
3. Set Status to "In Progress"
4. Create and checkout the feature branch (derive name from H1 heading, e.g. `feature/public-page`)
5. List the goals, then implement them one by one against the **DEV** environment only (Convex dev deployment, Clerk "LendLoop Dev", `[DEV]` n8n workflows)
